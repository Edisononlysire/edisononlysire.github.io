RESEARCH DIRECTION

研究路线

以生物系统为复杂系统研究的起点，逐步转向长程智能体决策。核心问题是：在动态且信息不完整的环境中，如何形成可靠态势、比较行动后果，并让机器建议始终可供人审查和修正？

统一研究问题

状态表征 → 干预推演 → 机制核验 → 任务状态维护 → 主动取证 → 人机协同指挥。各阶段对应具体项目、可验证的方法问题与明确分工，最终指向由人设定目标与行动边界的协同决策。

  1. 01

    从观测到态势 · OmniCell / GOformer / SPARSE

    把多源观测变成可比较的状态

    关键问题：如果模型混淆细胞自身的分子状态与周围的空间环境，后续推演与决策就没有可靠起点。

    具体工作：OmniCell 统一建模基因、细胞和组织空间关系；GOformer 区分细胞、基因与 GO 功能表示的读出；SPARSE 在冻结转录组表示上加入坐标感知、多尺度空间适配，同时用掩码表达重建约束分子语义。

    负责：在 OmniCell 中建立基线模型并承担数据分析、模型评估；为 GOformer 设计“统一线性探针”和“基因＋GO 注意力融合”分开的比较框架；几乎全程主导 SPARSE，从问题提出、方法结构到实验消融和论文撰写。

    研究衔接：这些工作得到“系统现在处于什么状态”的表征；要支持指挥，还必须回答干预后会怎样。

  2. 02

    从态势到后果 · DynPerturb

    推演行动的时间、强度与空间效应

    关键问题：同一干预在不同时间、剂量和组织位置可能产生不同结果，静态表征无法说明何时、何处值得行动。

    具体工作：DynPerturb 把时间编码、空间邻接和记忆模块放在同一动态框架，分析扰动传播、调控网络重连、反馈及候选干预窗口。

    负责：按稿件确定的分工参与数据分析与模型评估，开展消融实验，组织结果，并参与稿件准备和修订；重点检查结论对时间分辨率、特征选择与样本条件的敏感性。

    研究衔接：动态推演会给出可能的后果，但“模型预测”还需要机制链和独立证据来支撑。

  3. 03

    从预测到机制 · BiOmics / Discovery

    把判断变成可核查的证据链

    关键问题：相关性和模型分数不足以支持高影响判断；必须知道推断依据、证据来源，以及哪些环节尚未验证。

    具体工作：BiOmics 将知识图谱的显式关系、潜在表示和专用分析工具接入“检索—推理—预测”链路；BiOmics Discovery 进一步把候选发现与验证分开，先固定候选，再核对独立支持、反向证据和缺口。

    负责：主要设计 BiOmics 的研究构想与总体框架，明确知识、工具、智能体如何协作及推理链如何追溯；主导 Discovery 的问题拆解、候选固定、证据分级和验证路径设计。

    研究衔接：有来源的判断只有在长任务中保持有效、并能随新证据修正，才可以持续支持决策。

  4. 04

    从单次判断到长程任务 · EvoState / 法律 Agent

    维护会随行动变化的任务状态

    关键问题：长程任务中，旧事实可能失效、要求可能完成或重新打开，关键编号与路径却必须原样保留；同时行动还受权限与规则约束。

    具体工作：EvoState 用当前轨迹、事件记忆和任务状态分开保存执行证据、历史结果与现行约束；多操作编辑器依据新观测更新状态，依赖感知组装器为下一步保留精确引用。法律 Agent 实习 则把主体、条件、义务和例外转为可计算的任务约束。

    负责：重点参与 EvoState 的研究构想、三层状态划分、更新机制和评价框架设计；在法律 Agent 中侧重法律语言的结构化表达及可追溯推理流程。

    研究衔接：当任务状态可靠且边界清楚，系统才能判断还缺什么证据、是否有资格采取下一步行动。

  5. 05

    从被动判断到主动取证 · AEP-ECRG

    在不确定与对抗条件下选择下一步

    关键问题：证据不足时，立即行动可能过度响应；一味调查又会付出时间与资源成本。信息来源还可能在建立信任后发生变化。

    具体工作：AEP-ECRG 以公开观测、证据、信任状态和预算为输入，研究“是否调查、调查什么、何时处置”；规划中的 AEP 用候选行动价值学习主动取证，ECRG 用证据前提和风险边界约束高影响行动。

    负责：主要提出问题和整体研究框架，设计从公开证据、信念更新到主动取证与运行时治理的闭环，以及成本、收益、风险的比较口径。新版正式训练和治理增益仍在验证。

    研究衔接：这一步把机器从“给出一个答案”推进到“说明依据、缺口、调查价值和行动风险”，为人提供可审查的选项。

  6. 06

    长期研究方向

    人机协同指挥

    核心目标：建立人和机器共享的态势与决策界面，而不是让模型独自决定高影响行动。

    机器提供：多源态势、干预后果、机制与证据链、当前任务状态，以及不同调查或行动方案的成本和风险；每项建议标出来源、有效期、冲突与未验证处。

    人负责：设定目标、权限和风险阈值，追问依据，批准、修改或否决关键行动；新的观测和人工反馈进入下一轮状态更新。

    研究落点：现有工作分别提供表征、推演、解释、记忆和取证能力。下一阶段要在统一任务中检验这些能力能否形成可审查、可纠错的人机协同闭环。
