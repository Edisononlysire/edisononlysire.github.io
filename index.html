研究路线

研究生阶段的研究始于一个具体问题：相似的细胞表达谱处在不同的组织邻域，是否仍能用同一种方式理解？在OmniCell 中，负责基线模型构建、数据分析与评估，比较空间信息对细胞和组织层面任务的实际作用；随后为GOformer 设计细胞、基因与 GO 功能表示的读出和对照，区分预训练表征的质量与下游优化带来的增益。这些经历使关注点逐渐落到一个更基础的问题上：模型如何同时保留细胞的分子身份和所处的空间语境。在SPARSE 中，负责整体框架构思，将视觉模型中的多尺度思路转化为空间邻域建模方法，并完成下游任务的实验验证。

有了对当前状态的描述，下一步便是研究干预会如何改变它。在DynPerturb 中参与数据分析、模型评估和消融研究，检验干预的时间、强度与位置对细胞状态和调控关系的影响。对干预结果的分析又提出了新的要求：预测需要有可核查的机制依据。BiOmics 的主要贡献是整体研究框架设计，将知识关系、潜在表示和专业分析工具组织为可追溯的推理过程；在OncoEureka 中参与方法设计与分析，把竞争性肿瘤机制假设、预先确定的检验方案和来自不同数据的正反证据连起来，使初步发现能够转化为下一轮可执行的研究设计。

当研究对象扩展到持续行动的智能体，证据还需要随着任务推进而更新。参与EvoState 的研究构想和状态机制设计，区分当前执行记录、历史事件与现行要求，让新观察进入判断时不丢失关键约束。在北京大学法学院提出的LexStance 构想，则尝试把多方对话中分散的角色立场写成紧凑、可计算的状态，减少对原始对话的反复解读。在网络安全防御场景中，AEP-ECRG 将这一问题推进到动态信任与主动取证：历史可靠的来源也可能失信，因而需要权衡调查价值、响应时延与误处置成本，再判断证据是否足以支持隔离等高影响行动。

这些课题跨越生物系统与智能体，但始终在追问同一件事：判断依据如何形成，又如何在新观察出现后接受检验和修订。后续希望把状态表征、干预推演、机制核验与任务记忆放入连续的研究流程，使候选行动连同证据来源、适用条件和未解问题一起呈现，为关键判断保留审查与调整的空间。

实习经历

在跨学科场景中，把研究问题转化为可执行的模型和智能体方案。

华大北京创新中心 · AI 算法研发

OmniCell

预印本 · 共同第一作者

统一单细胞与空间转录组的基础模型

OmniCell 的思路是让同一模型同时学习细胞内的表达关系和细胞之间的空间关系。输入端先对连续表达值作软排序，再将目标细胞与空间邻居组织为序列；基因感知的混合专家模块编码表达值，带空间位置的注意力建模邻域，最后通过对称双线性输出耦合基因与细胞表示。这样的设计使模型能够在共享表征中读出细胞身份、基因共表达和组织结构；稿件用跨任务评测与模块消融检验各部分的作用。

负责基线模型和统一评测流程，梳理单细胞与空间任务各自的对照、数据划分和评价指标；开展数据分析、跨任务比较及模型评估，重点检查空间信息的加入是否改善组织层面的判断，同时保留细胞与基因层面的可辨性。参与模型方案讨论及论文结果组织。 查看预印本 ↗

华大北京创新中心 · AI 算法研发

GOformer

即将投稿

融合基因本体先验的单细胞基础模型

GOformer 试图解决全基因输入过长、仅靠表达相关性学习又缺少结构约束的问题。方法以基因—GO 二分图为信息瓶颈：图编码器把基因信号汇聚到功能节点，Transformer 只在较短的 GO 节点序列上建立全局关系，再由反向图解码器把功能上下文传回基因层。掩码表达重建与动量对比学习分别约束基因级预测和细胞级表示，使结构化先验、计算效率与下游迁移在同一框架中得到检验。

负责细胞、基因与 GO 三层表征的下游读出和对照方案设计，区分冻结特征的线性探针与任务微调后的效果；比较不同聚合与注意力融合方式，安排消融并梳理训练协议、任务设置和结果解释。论文正在准备投稿。

北京大学法学院

LexStance

概念探索

多角色法律对话中的立场编码

在包含多名角色的法律场景中，各方对同一主张的支持、反对或保留态度可能散落在多轮自然语言对话里。智能体如果只保存原话，后续步骤就需要反复阅读并重新判断人物立场。LexStance 探索将对话压缩为机器可读的状态记录，明确表示说话者、所针对的主张及当前态度，让人物之间的关系与态度变化更容易追踪。

提出以“角色—主张—态度”记录多方立场的结构化方向，梳理多轮对话中立场含糊、态度变化及相互冲突等需要编码的情形。拟比较保存原始对话与维护结构化状态时的立场识别准确性和 token 开销；编码形式与验证方案仍在设计中。

科研发表与在研项目

状态表征 · 独立第一作者

SPARSE

ICLR 2027 · 审稿中

Semantic-Preserving Adapter for Robust Spatial Embeddings

SPARSE 的出发点是把“已有模型懂得什么细胞”与“空间中这些细胞如何组织”分开学习：冻结转录组主干，只训练轻量空间适配器。它在每个中心细胞的固定邻域内按特征相似性合并 token，并传播坐标、加入空间旋转位置编码，再用跨尺度注意力和自顶向下融合把粗细两级信息带回细胞表示；这里的尺度指表示粒度，而非不断扩大物理半径。掩码表达重建约束适配器保留原有分子语义，因此空间信息的收益可以与细胞身份保留同时检验。

负责整体研究框架和从视觉多尺度建模到空间邻域表示的方案设计，并提出以表达重建约束语义保留。完成空间域识别、细胞类型区分、标签迁移及邻域组成预测等下游实验，组织基线比较与消融，检验方法在留出脑区、发育阶段和不同转录组主干上的迁移表现，并完成图表与论文论证。

动态推演 · 共同作者

DynPerturb

Nature Methods · 第二轮返修中 · IF 28.3（2025）

Dynamic Perturbation Modeling for Spatiotemporal Single-Cell Systems

DynPerturb 把干预建模为带时间、强度和作用位置的事件，而不只比较干预前后的终点。方法将调控或空间关系排列成真实时间顺序的动态图，通过时间编码、邻域注意力和带时间戳的节点记忆更新状态；连边预测学习关系如何重连，辅助节点分类使表示保留细胞或区域信息。不同干预设置下的结果主要来自潜在表示和网络结构的变化，用于提出可检验的响应窗口与反馈假设，而非直接证明因果效应。

按照稿件列明的分工，参与数据分析和模型评估，检查时间顺序下的关系预测、节点分类以及不同干预条件的稳定性；承担消融与对照结果整理，并参与稿件准备、修改和第二轮返修。重点关注时间、空间与记忆模块各自带来的解释增量。

机制解释 · 共同第一作者

BiOmics

Nature Biotechnology · 拟投稿 · IF 44.5（2025）

A Foundational Bio-Reasoning Agent for Traceable and Mechanistic Multi-omics Discovery

BiOmics 的核心问题是：模型能发现统计关联，却往往难以说明依据；知识检索能给出事实，却难以发现尚未记录的关联。框架因此并行维护显式推理空间和潜在表示空间：知识图谱提供可追溯的实体与关系路径，BRICK 工具链把组学数据接入检索、排序、分析和图表示学习，Agent 再按问题规划调用顺序。已知关系用于约束和回查解释，联合嵌入用于提出候选关联，形成“检索—推理—预测”的可核验闭环。

以共同第一作者身份负责研究构想与整体框架设计，提出显式知识路径与潜在表示协同的思路，规划 BiOmics-KG、BRICK 和 Agent 的职责、数据流及证据回查方式；设计从问题解析到候选预测的任务链，并与团队讨论变异、细胞注释和药物重定位任务的对照与论文论证。稿件仍在共同修改。

循证肿瘤学 · 共同第一作者

OncoEureka

The Lancet Summit · 摘要已投稿

循证肿瘤学假设生成与迭代研究设计智能体

OncoEureka 将肿瘤研究中的“发现线索”改写为可反驳的研究程序。智能体先界定问题和数据边界，提出相互竞争的机制假设，并在查看候选特异结果前固定方向性预测、分析方案与验证路径；随后用发现集、留出集和外部证据交叉检验，同时记录支持、反向结果与无法判定之处。急性髓系白血病药物敏感性和宫颈癌治疗反应两个例子展示了如何从初始关联推进到下一轮纵向、单细胞、空间或功能实验设计。

以共同第一作者身份参与方法设计与分析，重点负责将候选提出、预先规定的检验和后续验证明确分开；梳理不同来源证据的可比性与反证标准，把初步关联整理为具有方向性预测的研究问题。

持续决策 · 共同第一作者

EvoState

ICLR 2027 · 审稿中

Multi-Operation Context-State Transitions for Long-Horizon LLM Agents

EvoState 把长程智能体的上下文压缩视为状态维护问题：新观察不仅增加信息，也可能让旧事实失效。框架分别保存正在执行的精确证据、历史事件结果以及当前有效的事实和未完成要求；多操作编辑器按证据更新、合并或撤销状态，依赖感知组装器再为下一步行动选取必要信息。精确编号、路径和未解决依赖可越过柔性 token 目标，避免“摘要更短”却丢掉执行前提。

参与研究问题、三类状态及其保留规则的设计，明确精确引用、历史结果、当前事实和未完成要求各应如何更新；参与多操作编辑和依赖感知组装原则，讨论过时事实失效、下一步行动依赖与软预算之间的取舍，并参与评测和消融设计。

网络安全防御 · 在研

AEP-ECRG

探索中

AEP-ECRG 面向网络安全防御中的两类不确定性：告警和遥测不足以区分真实威胁与正常变化；历史可信的日志、身份或检测来源被接管后，仍可能给出形式上有效的错误声明。框架将来源的长期信誉与单条声明的可信度分开维护，根据支持证据、反证和时间变化更新信任。主动证据策略（AEP）权衡调查成本、响应时延与误隔离的业务损失，选择继续观测、核验来源或采取防御行动；证据约束治理器（ECRG）在隔离、移除等高影响动作前，核查证据是否与目标和动作相符，避免把有效签名或既往信誉直接当作处置依据。

负责提出以主动取证和证据约束治理连接决策策略与执行边界的研究框架，设计告警歧义、可信来源背叛与合法变化的配对场景，以及公开证据、来源信任、调查预算和安全效用之间的关系。进一步规划来源核验、金丝雀试探和有信息／无信息／不试探的对照，用来区分“发现来源可疑”与“已有足够证据采取限制性措施”。目前工程原型与评测协议仍在完善，正式模型效果尚待验证。
